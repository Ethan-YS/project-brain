# STATUS — Current Development State

> **What this file answers**: "Where are we? Next step? What's blocked?"
>
> **Character**: **instantaneous state**. **Soft cap ~80 lines or ~6,000 characters**, whichever trips first (v2.9) — a 70-line STATUS with 1,300-character lines is a log, not a state. Safe to overwrite.
> Settle valuable content into `MAP.md` (structural changes) or `DECISIONS.md` (rationale) **first**, then overwrite.
>
> **vs `brain/topics/planning/`**: planning = roadmap (what to build); STATUS = this session's state (what we're on, where we're stuck).
> **vs `HANDOFF.md`**: STATUS = steady state, overwritten at each session end; HANDOFF = the shift report written at a switch.
>
> **Who reads this**: every new session.
>
> **Multi-workstream (v2.1)**: copy this template as `STATUS_<workstream>.md` (e.g., `STATUS_dev.md`), one per workstream. See METHODOLOGY §3.5.
>
> **Concurrent windows (v2.8)**: uncomment the two cross-workstream sections below; name other workstreams, never their windows. See METHODOLOGY §3.6.
